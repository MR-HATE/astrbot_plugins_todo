# 正例与反例

## 应当触发

**例 1：多件事 + 相对时间**

> 用户：下周要去上海出差，周三前订好酒店和机票，出发前一天提醒我带身份证

```
ms_todo_import_tasks(
  plan_name="上海出差",
  tasks=[
    {"title": "订好酒店", "due_date": "2026-09-16", "importance": "high"},
    {"title": "订好机票", "due_date": "2026-09-16", "importance": "high"},
    {"title": "收拾行李与证件", "due_date": "2026-09-15",
     "remind_at": "2026-09-15T20:00", "note": "身份证、充电器、常用药"}
  ])
```

要点：三件独立的事 = 三个 task；「订酒店」和「订机票」不合并；
只有用户点名的那件事才有提醒。

**例 2：一件事带子步骤**

> 用户：这个月要把搬家搞定，得找搬家公司、打包、还有把宽带迁过去

```
ms_todo_import_tasks(
  plan_name="搬家",
  tasks=[{
    "title": "完成搬家",
    "steps": ["找搬家公司并比价", "打包行李", "办理宽带迁移"]
  }])
```

要点：**不要**拆成三个 task——它们属于同一件事；用 `steps` 表达子步骤。

**例 3：用户自己给了列表名**

> 用户：帮我记到「工作」列表里，周五前把季度报告发给老板

```
ms_todo_import_tasks(list_name="工作",
  tasks=[{"title": "把季度报告发给老板", "due_date": "2026-09-18", "importance": "high"}])
```

## 不应触发（或先追问）

| 用户的话 | 正确反应 |
| --- | --- |
| 「最近好忙啊」 | 不调用工具；可以问"要不要我帮你把要做的事理成清单？" |
| 「Microsoft To Do 怎么用？」 | 正常回答；不调用工具 |
| 「我刚从上海回来」 | 不调用工具（陈述已完成的事，不是待办） |
| 「帮我看看今天有什么要做的」 | 本版本还没有查询待办条目的工具 → 如实说明，或引导用户直接看 To Do 客户端 |
| 「把那个事处理一下」 | 无法确定"那个事"是什么 → 先追问，不要臆造任务 |
| 「明天开会」 | 可触发，但缺时间/地点 → 追问"几点？需要提醒吗？"，或先按 `due_date=明天` 记录 |
| 「每天都要背单词」 | 不支持重复任务 → 按最近一次记录并明确告知用户 |

## 反例（常见错误）

❌ **过度拆分**
> 「给客户回邮件」→ 拆成 `打开邮箱` / `写邮件` / `点击发送`
✅ 一个 task：`给客户回邮件`

❌ **编造日期**
> 用户：「有空的时候把书看完」→ 填 `due_date=今天`
✅ 不填日期；回复里说明"没有设截止时间"

❌ **默认加提醒**
> 用户：「记一下明天交房租」→ 填 `remind_at=明天09:00`
✅ 不填 `remind_at`；除非用户说"提醒我"

❌ **所有任务都标 high**
✅ 只有用户明确说重要/紧急的才 `high`

❌ **跳过确认直接写**
> 用户刚说完计划，就调用 `confirmed=true`
✅ 先 `confirmed` 留空拿预览 → 发给用户 → 等确认

❌ **预览里有警告却不说**
> 工具返回「⚠️ 第 2 项：无法识别日期『月底』，已忽略截止时间」
✅ 原样转达："『月底』我没法确定具体日期，这项先不设截止时间，你可以告诉我具体哪天"

❌ **把时间写进标题**
> `title="周三之前订酒店（重要）"`
✅ `title="订酒店"` + `due_date="2026-09-16"` + `importance="high"`

## 确认环节的话术

预览发出后，等用户明确表态：

- 确认类：「确认」「可以」「导入吧」「就这样」→ `ms_todo_confirm_import(action="confirm")`
- 否定类：「算了」「取消」「不用了」→ `ms_todo_confirm_import(action="cancel")`
- 修改类：「第 2 项改到周五」→ **重新调用** `ms_todo_import_tasks` 生成新预览，
  不要直接改旧计划；改完再让用户确认一次。
- 含糊类：「嗯……」→ 再问一句"要现在导入吗？"，不要自行判断。
