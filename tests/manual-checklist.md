# 手动端到端验收清单

自动化测试（`python tests/run_tests.py`）用的是假 Graph / 假定时任务，覆盖不到**真机行为**：
真实授权、真实 To Do 界面、真实到点提醒。这份清单用于每次发版前在真机上过一遍。

约定：`[ ]` 未验证，`[x]` 通过，`[!]` 有问题（在备注里写清楚现象）。

---

## 0. 前置

- [ ] 插件已安装到 `AstrBot/data/plugins/`，WebUI 插件页能看到且已启用
- [ ] 配置项 `client_id` 已填（Entra 应用 ID），`tenant` 与账号类型匹配
      （个人账号用 `consumers`，要用工作/学校账号得改 `common`）
- [ ] 「身份验证」页已开启**允许公共客户端流**
- [ ] 已点过「重载插件」（不是只刷新浏览器）
- [ ] 日志里出现 `已注册 12 个 LLM 工具`，且包含 `ms_todo_delete_list`

> ⚠️ 若这里就不对，先别往下测——大概率是代码没同步到运行 AstrBot 的那台机器。

## 1. 授权

- [ ] `/todo login` → 返回授权网址 + 设备码
- [ ] 在**手机浏览器**完成登录后，机器人主动发来「绑定成功」
- [ ] `/todo status` → 显示账号、token 有效期、refresh_token 已保存
- [ ] 重启 AstrBot 后 `/todo status` 仍然已绑定（验证 KV 持久化）
- [ ] `/todo logout` → 再 `/todo status` 显示未绑定；再 `/todo login` 能重新绑定

失败路径：

- [ ] 把 `client_id` 改错 → `/todo login` 给出可读的错误（不是堆栈）
- [ ] 未绑定时直接说「记一下明天开会」→ 机器人引导你先 `/todo login`

## 2. 导入（两阶段提交）

在**已绑定的那个平台**里（注意：账号按「平台 + 用户」隔离，QQ 绑的账号在 WebUI 的 Chat 页不算数）测试。

- [ ] 说一句话计划 → 返回**预览卡片**（不是直接写入）
- [ ] 预览里日期换算正确（和当天日期对照）
- [ ] 此时去 To Do App 看，**没有**新增任务（确认前不落库）
- [ ] 回复「确认」→ 返回写入回执，To Do App 里出现任务
- [ ] 核对：标题、截止时间、优先级（🔴 = 高）、子步骤（To Do 里的「步骤」）
- [ ] 另起一份，回复「取消」→ 没有写入
- [ ] 预览里出现「⚠️ 需要留意」时，机器人把它转达了
- [ ] 同一份清单再导入一次 → 提示「跳过 N 项（To Do 里已有同名同期的待办）」

边界：

- [ ] 「月底」「下个月」这类模糊时间 → 不猜日期，并且说明了
- [ ] 一句话里 5 件事以上 → 走批量（日志或耗时上能看出），全部写入
- [ ] 计划名归纳出的列表名合理（会在 To Do 里**新建列表**，去 `/todo lists` 能看到）

## 3. 查询

- [ ] `/todo today` → 列出未完成且今天到期/已逾期的（含来源列表名）
- [ ] 说「上周的事都完成了吗」→ 走 `completed` 范围，如实回答
- [ ] 手动在 To Do App 里勾掉一条 → 再查，状态变成 ✅

## 4. 增删改

- [ ] 「把 XX 改到周五」→ 截止日期变了，**时刻保持不变**
- [ ] 「XX 做完了」→ 变已完成；再试「XX 还没做完，改回来」→ 变未完成
- [ ] 「删掉 XX」→ **先给出"即将删除"清单**；回复确认后才真删
- [ ] 造两条标题相近的任务（如「写周报」「写季度报告」），说「把写改一下」
      → 返回**候选清单**，没有自己挑一条改掉
- [ ] 「XX 下面加上 A、B 两个步骤」→ To Do 里出现子步骤

## 5. 删除列表

- [ ] `/todo dellist <列表名>` → 提示"该列表下有 N 个任务（其中 M 个未完成）"
- [ ] 回复确认 → 列表和里面的任务一起消失
- [ ] 尝试删默认列表（`Tasks`）→ 被拒绝并说明原因
- [ ] 用一个会匹配到多个列表的短名 → 返回候选让用户选

## 6. 到点提醒（最关键的一项）

最快的验证方式：设一个 **2 分钟后**的提醒。

- [ ] 说「两分钟后提醒我喝水」→ 确认后回执里有「⏰ 已为 1 项创建到点提醒」
- [ ] WebUI 左侧「**未来任务**」页能看到 `待办提醒 · 喝水`，下次运行时间正确
- [ ] **等到点** → 机器人在同一个会话里主动提醒
- [ ] `/todo done 喝水` → 回执里说明"它的到点提醒已一并取消"
- [ ] 回「未来任务」页确认那条任务**消失了**
- [ ] 重复提醒：「每天早上 8 点提醒我记账」→ 未来任务页里是 cron 形式（每天）
- [ ] 关掉配置项 `reminder_enabled` → 再导入带提醒的任务，回执说明"只写入了 To Do 内的提醒"

平台差异（预期行为，不是 bug）：

- [ ] 在 **WebUI 的 Chat 页**测试 → 提示"当前平台 webchat 不支持机器人主动发消息"，
      任务照常写入 To Do，但不会创建定时任务

## 7. 失败路径

- [ ] 断网 / 改错域名 → 报错可读，插件不崩
- [ ] 在 To Do 里手动删掉某条 → 再执行针对它的操作 → 给出"没有找到"而不是异常堆栈
- [ ] 连续快速导入多次 → 不出现重复任务
